## 1.3.1
- NeoForge loader version is now more lenient and allows older patch versions than the project's default (which was `21.1.256`).

<br>

## 1.3.0
- Changed the default contraption drilling speed to `0.5x`
- Changed the default contraption drilling drop chance to `0.25x`
- Improved the mod icon.
- Added a comparison video/GIF to the readme.

<br>

## 1.2.0
- Added the ability to configure the mod using the in-game "Mods > Config" menu in Singleplayer worlds.
- Added an ugly temporary icon.
- Fixed a bug where contraptions would get stuck for IRL years when the speed multiplier was ever set to 0.0, even after a server restart.

<br>

## 1.1.0
- Added the ability to override multipliers in the config for any amount of dimensions.  
  This could be used to undo the applied nerf in specific mining dimensions, and punish different dimensions with different multiplier values.

<br>

## 1.0.0
Initial release:
- Configurable multiplier for Drill Contraption mining speed.
- Configurable multiplier for Drill Contraption mining drop chances.
- Toggle to apply the multipliers to only Drills or also Saws and other breaking blocks.
